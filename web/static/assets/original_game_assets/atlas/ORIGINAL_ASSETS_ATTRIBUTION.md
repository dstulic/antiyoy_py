# Original Game Assets Attribution

## Source

These assets are copied from the **Antiyoy HD** project, which is the source code for the game Antiyoy (also known as Antiyoy Online).

## Original Project Information

- **Project**: Antiyoy HD
- **Repository**: https://github.com/yiotro/antiyoy_hd (or similar)
- **Developer**: yiotro (yiotro93@gmail.com)
- **Project Description**: Antiyoy HD is the iOS version of Antiyoy Online, an offline version without multiplayer.

## License and Usage

According to the original project's README:
> "If you want to make a mod for Antiyoy, it is better to use this version. The source code for this version was mostly written from scratch and it is much better than what was in the initial version. **Please keep your mod as a non commercial project.**"

## Assets Location

Original assets are located at:
- Source: `../../antiyoy_hd/assets/game/atlas/`
- This copy: `antiyoy_py/web/static/assets/original_game_assets/atlas/`

## Assets Included

- Game piece sprites (peasant, spearman, baron, knight, tower, city, etc.)
- Hex tile graphics
- UI elements (selection borders, move zones, etc.)
- Visual indicators (defense indicators, exclamation marks, etc.)

## Usage in This Project

These assets are used in the Python port of Antiyoy for:
- Web interface rendering
- Game board visualization
- Piece and hex display
